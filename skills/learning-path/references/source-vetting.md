# Vetting lesson sources

Score each candidate lesson 0-2 on the criteria below and keep the highest scorers. Do not show the scores unless the user asks; use them to decide and to explain choices briefly.

| Criterion | 0 | 1 | 2 |
| - | - | - | - |
| Fit with the module outcome | Off-topic or too broad | Partly covers it | Directly teaches the outcome |
| Level match | Far too basic or advanced | Slightly off | Matches the user's level |
| Accuracy and credibility | Errors or no expertise visible | Plausible, unverified | Credentialed author, institution, or well-sourced |
| Recency (fast-changing topics) | Outdated version or advice | Somewhat dated | Current, or topic is stable |
| Clarity and pacing | Hard to follow | Acceptable | Clear structure, good examples |
| Practical value | Talk only | Some examples | Worked examples or exercises |

## Red flags (drop or warn)

- Clickbait title that the content does not deliver.
- Undisclosed sponsorship or a product pitch posing as teaching.
- Claims with no sources on health, legal, tax or investment topics.
- Covers an old version of a tool when the topic changes quickly.
- Very low-effort reuploads of other people's work.

## Rules

- For health, legal, tax and investment topics, prefer universities, hospitals, public institutions and established professional bodies, and keep the plan at the level of general education.
- When credible sources disagree, tell the user and include one lesson for each view instead of choosing silently.
- If only one acceptable lesson exists for a module, say that plainly rather than padding the list.
- Prefer a mix of formats across the plan: a lecture, a worked walkthrough, and a practice session.
